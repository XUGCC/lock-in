# LOCK IN · GitHub Pages 本地记录版

这是纯静态 PWA，不需要服务器、数据库或域名。每位使用者的练习记录保存在自己的浏览器中，互不影响。

当前版本包含：

- 黑胶贴纸式月历打卡、连续练习统计与当日 Live 唱片动效
- 内置或自定义练习元素（自定义元素统一使用 `✣` 图标）
- 动作、状态、时长、笔记与 BPM 记录
- 每天唯一一首“今日最爱”，网易云歌曲链接可自动识别歌名、歌手和专辑封面
- 识别不到封面时自动使用本地原创默认封面，已识别文字仍可手动修正
- 记录编辑、筛选、删除，以及 JSON 导入/导出
- 本地内置 GSAP 动效，不依赖境外 CDN；断网后仍可继续使用

网易云音乐采用分享链接方式连接，不读取账号、歌单或听歌历史。自动识别时只会把歌曲 ID 发送给公开的 Meting 解析服务；网易云短链接会先通过 Unshorten.me 取得最终歌曲地址。识别后的歌名、歌手和链接仍保存在本机。外部服务不可用时可以手动填写，封面会回退到本地默认图。

## 发布到 GitHub Pages

1. GitHub 仓库：`XUGCC/lock-in`。
2. 正式文件位于仓库根目录。
3. 打开仓库的 **Settings → Pages**，在 **Build and deployment** 中选择 **Deploy from a branch**，分支选 `main` 和 `/ (root)`，然后保存。
4. 发布地址：`https://xugcc.github.io/lock-in/`。

## 小米 / Android 使用

使用 Chrome 打开链接后，点右上角菜单选择“安装应用”或“添加到主屏幕”。小米浏览器一般在菜单中提供“添加到桌面”或“添加到主屏幕”。

本地数据依赖浏览器存储：清除浏览器数据、换浏览器或换手机后不会自动保留。请定期使用页面底部的 `⇩ JSON` 导出备份，并在新设备上通过 `⇧ JSON` 导入。
